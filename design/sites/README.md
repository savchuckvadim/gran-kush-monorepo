# Два сайта продукта — прототипы

Один продукт (CRM для клубов), два бренда, два разных сайта. Это не перекраска одного макета:
у каждого своя структура страниц, навигация и движение. Тема CRM и прочие направления живут
отдельно, в `../crm-themes/` и `../marketing/`.

| | PafPaf (`pafpaf/`) | Nagual (`nagual/`) |
|---|---|---|
| Идея | «тихий космос»: продуктовые страницы в духе Apple | иллюминированный кодекс, ритуал |
| Навигация | две полосы сверху: глобальная и панель продукта | столбец глав I–VII слева; на телефоне — «астролябия» с оглавлением |
| Первый экран | планета поднимается, панель CRM садится на горизонт | портал-астролябия из сакральной геометрии |
| Функции | разделы с визуалом у каждой функции, сцена «вход за секунду» при прокрутке | колода из 8 арканов таро, карты переворачиваются |
| Цены | три тарифа, калькулятор, сравнение, вопросы | алтарь из трёх створок, онбординг фазами луны, «оракул» вместо FAQ |
| Блог | — | гербарий: растения прорастают при прокрутке |
| Режимы | чёрные и белые секции чередуются | тёмный и «зелёные чернила на бумаге» |
| Языки | ES / RU | ES / RU |
| Домен | `paf-paf.app` | `nagual.club` |

У PafPaf три варианта, все остаются до выбора:

| Вариант | Папка | Суть |
|---|---|---|
| Белый минимализм в духе SmokApp | `../marketing/` (направление PafPaf) | одна страница, белые карточки, рамки с перетекающим градиентом, дым в карточках |
| «Тихий космос» в духе Apple | `pafpaf/` | 4 страницы, звёзды и планета, буквы из дыма, сцены при прокрутке |
| Жидкий | `pafpaf-liquid/` | 2 страницы: живой WebGL-дым под всей страницей, «жидкое стекло» (как Liquid Glass в iOS 26), жидкие компоненты — капля в навигации, кнопки с волной, колба лимита, сливающиеся клубы, матовое стекло по ролям; день и ночь |

Тарифы одинаковые: Calada — до 300 участников, Club — до 1 500, Cadena — без лимита. Цены —
примеры прототипа.

Первые страницы (`index.html`) начинаются с `<title>` без `<!doctype>`: хост артефактов
оборачивает их в документ сам. Остальные страницы — полные документы.

Исходник Nagual собирал генератор (общая разметка, SVG, проверка ключей перевода); готовые файлы
статичные и правятся руками. Русские строки Nagual — в словаре `RU` в `nagual/nagual.js`.
