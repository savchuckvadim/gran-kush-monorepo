# PafPaf — «тихий космос», прототип сайта

Вариант сайта PafPaf в стиле продуктовых страниц Apple. Тихий минимализм, чёрный космос
и белые страницы, один акцент — сияние бренда (фиолетовый → розовый → янтарный).
Домен: `paf-paf.app`, CRM — `crm.paf-paf.app`.

Это прототип, а не код приложения. Открыть `index.html` в Chrome. Язык (ES / RU) переключается
в шапке и в футере.

## Приёмы

- **Звёзды.** Три слоя на одном canvas; при прокрутке слои едут с разной скоростью, за курсором —
  лёгкий сдвиг. Canvas работает, только пока на экране тёмная секция.
- **Сцены при прокрутке.** Секция с `data-scrolly` получает `--p` от 0 до 1, CSS двигает элементы
  по нему. Так поднимается планета в hero и переключаются шаги в сцене входа (`data-steps`).
- **Буквы из дыма.** Заголовки `.smoke-text` разбиваются на буквы. Буквы проявляются из размытия
  по очереди, за заголовком hero — фиолетовая туманность из видео дыма. Идея пришла из прошлого
  прототипа, где она понравилась.
- **Дым в карточках.** Тёмные карточки карусели с тем же видео. Оно грузится и играет, только
  когда карточка рядом с экраном.
- **Параллакс-луны** (`data-speed`), орбиты на CSS, счётчики, кольцо лимита, наклон карты за курсором.
- Шапка в два этажа, как у Apple: глобальная навигация и липкая панель продукта. Панель продукта
  становится светлой над белыми секциями.
- `prefers-reduced-motion` выключает сцены, буквы и анимации.

## Для продакшена

- Шрифт: на устройствах Apple — системный SF, на остальных — Inter. В Next — `next/font`.
- Первую страницу (`index.html`) хост артефактов оборачивает в документ сам, поэтому в ней нет
  `<!doctype>`. Остальные страницы — полные документы.
- Видео: Mixkit, бесплатная лицензия (см. `../../marketing/README.md`). Для продакшена — перекодировать
  и дать постер.
