# Philosophy

Бренд, позиционирование и смысловая рамка продукта. Не техническая документация — это то, откуда берутся тексты, визуал, имя и продуктовые приоритеты.

## Документы

- [Философия бренда](./BRAND_PHILOSOPHY.md) — концепция «мы — тональ клуба», манифест, бренд-платформа, тон голоса, анти-словарь, слоганы (ru/en/es)
- [Нейминг и домены](./NAMING_AND_DOMAINS.md) — 41 вариант названия, проверенная доступность доменов, рекомендация и план покупки

## Статус

**Черновик на утверждение.** Ничего не куплено, имя не выбрано.

Блокеры перед покупкой домена:

- [ ] выбрать имя из шорт-листа (Baquiano / Quilate / Templanza)
- [ ] проверка EUIPO по классам 9, 42, 35
- [ ] перепроверка `.es` у регистратора (данные получены по DNS-делегации)
- [ ] тест имени на носителях языка

## Связь с остальной документацией

Концепция влияет на продукт, а не только на маркетинг — см. раздел «Что это меняет в продукте» в [BRAND_PHILOSOPHY.md](./BRAND_PHILOSOPHY.md). Ближайшие пересечения: `Modo inspección` (режим проверки) и правило `templanza` при оценке новых модулей в [FLEXIBLE_CRM_DOMAIN_TASKS.md](../crm/FLEXIBLE_CRM_DOMAIN_TASKS.md).
