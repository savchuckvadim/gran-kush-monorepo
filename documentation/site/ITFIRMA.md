# IT-firma — сайт студии (`apps/itfirma`)

Сайт-визитка IT-студии: услуги разработки, собственные продукты, форма заявки. Юридически за ним стоит
autónomo, на сайте — название студии IT-firma. Студия — вендор чистых инсталляций (Ink Space, Plis Plas)
и приложений для Битрикс24. **PafPaf на сайте не упоминается** (правило мульти-ниш: клубы отдельно).

|                      |                                                                           |
| -------------------- | ------------------------------------------------------------------------- |
| Порт                 | `5003`                                                                    |
| Языки                | `es` (по умолчанию), `en`, `ru`, `ca`                                     |
| CMS                  | нет: тексты в `modules/shared/config/i18n/messages/*.json`                |
| Темы                 | Black (по умолчанию), Cristal, Sociopath, Coqueta — палитры из скинов CRM |
| Домен, почта         | `installation.json`                                                       |
| Владелец, NIF, адрес | `modules/shared/config/site.ts` (`OWNER`) — сейчас заглушки               |

## Запуск

```bash
cp apps/itfirma/.env.example apps/itfirma/.env   # каналы доставки заявок
pnpm --filter itfirma dev                        # http://localhost:5003/es
```

## Устройство

- **Одна страница** `app/[locale]/page.tsx` собирает секции из `modules/home/`: hero, лента стека,
  услуги, продукты, процесс, студия, контакты. Якоря меню — `HOME_SECTIONS` в `config/routes.ts`.
- **Юридические страницы** `/{locale}/legal/{aviso-legal|privacidad|cookies}` — тексты в
  `modules/legal/content/<locale>.ts`, подстановки `{name}`, `{nif}`, `{address}`, `{email}`, `{domain}`.
- **Темы.** Токены — `app/globals.css` под `[data-skin]`, список — `config/skins.ts`. Скрипт в `<head>`
  ставит сохранённую тему до отрисовки, `SkinSync` возвращает её после монтирования. В браузере
  хранится только выбор темы (localStorage), cookies нет.
- **Эффекты** без библиотек: фон с сеткой или «фото» и плавающими пятнами, свечение за курсором,
  подсветка рамки карточки, появление блоков при прокрутке, смена слов в заголовке, лента стека.
  `prefers-reduced-motion` всё это выключает.
- **Продукты** берут палитру и домен из `@workspace/brand`; ссылка появляется, когда инсталляция
  `released`.

## Заявки

`POST /api/lead` (`app/api/lead/route.ts`), схема — `modules/lead/schema.ts` (её же проверяет форма).

| Ответ | Когда                                                                                         |
| ----- | --------------------------------------------------------------------------------------------- |
| 200   | доставлено хотя бы в один канал; или заполнено поле-ловушка `website` (бот, заявка выброшена) |
| 400   | не прошла схема                                                                               |
| 429   | больше 5 заявок за 10 минут с одного IP (счётчик в памяти процесса)                           |
| 503   | не настроен ни один канал или все каналы упали — форма просит написать на почту               |

Каналы — env, см. `.env.example`: SMTP (`MAIL_*`, `LEAD_TO`) и Telegram (`TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHAT_ID`). Заявка не хранится на сервере.
