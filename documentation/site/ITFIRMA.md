# IT-firma — сайт студии (`apps/itfirma`)

Сайт IT-студии: услуги разработки, кейсы, статьи, форма заявки. Юридически за ним стоит autónomo, на
сайте — компания IT-firma (на главной говорим от лица студии, основателя называем один раз в блоке
«Студия»). Студия — вендор чистых инсталляций (Ink Space, Plis Plas) и приложений для Битрикс24.
**PafPaf на сайте не упоминается** (правило мульти-ниш: клубы отдельно).

Сайт подтверждает перед юристом два вида деятельности: **разработка ПО на заказ** и **собственные SaaS
по подписке**. Оба названы в заголовке страницы, подзаголовке, блоке «Студия» и в правовой информации
(`aviso-legal`, второй абзац). Меняя тексты, сохраняйте эти формулировки.

|                      |                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------- |
| Порт                 | `5003`                                                                                   |
| Языки                | `es` (по умолчанию), `en`, `ru`, `uk`, `ca`                                              |
| CMS                  | нет: тексты интерфейса в `modules/shared/config/i18n/messages/*.json`, контент в TS      |
| Темы                 | Black (по умолчанию, тёмная и светлая), Cristal, Sociopath, Coqueta — палитры скинов CRM |
| Домен, почта         | `installation.json`                                                                      |
| Владелец, NIF, адрес | `modules/shared/config/site.ts` (`OWNER`) — сейчас заглушки                              |
| Деплой               | `infra/dokploy/itfirma`, раздел «Сайт студии IT-firma» в его README                      |

## Запуск

```bash
cp apps/itfirma/.env.example apps/itfirma/.env   # каналы доставки заявок
pnpm --filter itfirma dev                        # http://localhost:5003/es
```

## Страницы

| Адрес                       | Что                                                         | Откуда тексты                                 |
| --------------------------- | ----------------------------------------------------------- | --------------------------------------------- |
| `/{locale}`                 | главная: hero, услуги, Битрикс24, кейсы, процесс и форматы, | `messages/<locale>.json`                      |
|                             | студия, статьи, FAQ, призыв, форма                          |                                               |
| `/{locale}/services/{slug}` | восемь страниц услуг                                        | `modules/content/services/<locale>/<key>.ts`  |
| `/{locale}/insights`        | список статей                                               | `modules/content/articles/<locale>/<slug>.ts` |
| `/{locale}/insights/{slug}` | статья                                                      | там же                                        |
| `/{locale}/legal/{doc}`     | aviso legal, privacidad, cookies                            | `modules/legal/content/<locale>.ts`           |

- **Ключи услуг и адреса** — `config/services.ts` (`SERVICE_SLUGS`, одинаковые на всех языках),
  статьи — `config/articles.ts`. Новая услуга: ключ в `SERVICE_KEYS`, тексты карточки в
  `services.items.<key>` всех пяти JSON, страница в пяти `content/services/<locale>/`.
- **Якоря главной и меню** — `HOME_SECTIONS` и `MENU_SECTIONS` в `config/routes.ts`. Продукты скрыты,
  пока список `LIVE_PRODUCTS` в `config/products.ts` пуст.
- **Кнопка заявки** — один компонент `CtaLink` с одной формулировкой `cta.request` на весь сайт
  (шапка, hero, блоки, подвал, страницы услуг и статей); ведёт на форму `/#contact`.
- **Правило текстов**: без тире-украшений (`—`), числа и обещания только те, что можно выполнить;
  телефон на сайте не публикуем.

## Оформление

- **Темы.** Токены — `app/globals.css` под `[data-skin]` и `[data-skin].dark`, список — `config/skins.ts`.
  Без сохранённого выбора режим берётся из настроек устройства. `SKIN_SCRIPT` в `<head>` ставит
  сохранённую тему до отрисовки, `SkinSync` возвращает её после монтирования. В браузере хранится
  только выбор темы (localStorage), cookies нет.
- **Шапка.** От 1024px — липкая полоса сверху: логотип, разделы, `ModeToggle` (солнце/луна),
  `PaletteMenu` (четыре кружка-градиента), `LocaleMenu` (код языка, список из пяти) и кнопка заявки.
  Ниже 1024px — как на сайте PafPaf: стеклянная капсула `MobileBar` внизу экрана (знак «[IT]»,
  «Услуги», «Кейсы», «Статьи» с бегущей подсветкой, бургер) и стеклянная плашка `MobileTopControls`
  вверху справа (режим, палитра, язык, кнопка заявки; уже 360px кнопка остаётся только в бургере).
  Подсветка на главной следует за прокруткой (`useActiveSection` на IntersectionObserver), на
  страницах услуг и статей — за адресом. Бургер `MobileMenu` открывает стеклянную шторку над
  капсулой; шторка в portal, потому что `backdrop-filter` капсулы привязал бы `fixed` к ней.
  Закрытие по Escape и клику снаружи — общий `useDismiss`. Стекло — класс `.glass` в слое
  components (с запасным сплошным фоном при `prefers-reduced-transparency`), кнопки шапки внутри
  стекла без своей рамки. `body` ниже 1024px получает отступы сверху и снизу под плашку и капсулу.
- **Ширина** — класс `.wrap` (84rem, отступ 16px на телефоне); секции `py-16 md:py-32`.
- **Эффекты** без библиотек, в `modules/shared/ui/effects/`: `AuroraCanvas` (WebGL, hero и страницы
  услуг), `DotGrid` (услуги), `ThreadLines` (блок Битрикс24), `Particles` (призыв). Общий хук
  `useCanvasScene` рисует только на экране и во вкладке, при `prefers-reduced-motion` один кадр.
  Цвета берутся из токенов темы (`useSkinColors`), поэтому эффекты перекрашиваются вместе с темой.
- **Движение текста**: `SplitText` (слова заголовка hero), `Reveal` (появление блоков), `.shine`
  (блик на кнопке), одна бегущая лента стека под hero.

## Заявки

`POST /api/lead` (`app/api/lead/route.ts`), схема — `modules/lead/schema.ts` (её же проверяет форма).

| Ответ | Когда                                                                                         |
| ----- | --------------------------------------------------------------------------------------------- |
| 200   | доставлено хотя бы в один канал; или заполнено поле-ловушка `website` (бот, заявка выброшена) |
| 400   | не прошла схема                                                                               |
| 429   | больше 5 заявок за 10 минут с одного IP (счётчик в памяти процесса)                           |
| 503   | не настроен ни один канал или все каналы упали — форма просит написать на почту               |

Каналы — env, см. `.env.example`: SMTP (`MAIL_*`, `LEAD_TO`) и Telegram (`TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHAT_ID`). Заявка не хранится на сервере.
