# Финансы: требования по итогам исследования

Дата: 2026-10-20. Исследование перед TASK-796 ([finance-accounting](finance-accounting.md)) по запросу
Вадима: что обязаны вести клубы и студии в Испании, что нужно владельцу для управления, как устроен
импорт расходов таблицей у референсных приложений. Источники в конце; суммы и сроки сверять с gestor
перед релизом каждой формы.

Установка Вадима: **издержки нужны сразу, с загрузкой таблицей и примером таблицы для скачивания, но
без усложнения**.

## 1. Что требует закон

### Asociación (клубы PafPaf)

- Ley Orgánica 1/2002, art. 14: актуальный список членов, **бухгалтерия, дающая «imagen fiel del
  patrimonio, del resultado y de la situación financiera»**, инвентарь имущества, книга протоколов.
  Строгого плана счетов для обычной (не declarada de utilidad pública) ассоциации закон не навязывает;
  адаптация PGC для некоммерческих (RD 1491/2011) обязательна для фондов и ассоциаций utilidad pública,
  остальным — ориентир. Список членов и протоколы у нас уже есть в CRM (участники, журнал); инвентарь —
  это склад плюс основные средства.
- Impuesto sobre Sociedades: ассоциация — **entidad parcialmente exenta (art. 9.3 LIS)**. Освобождены
  членские взносы и доходы от уставной деятельности; **доходы от explotación económica облагаются**.
  Декларацию (Modelo 200) можно не подавать только при трёх условиях сразу: доходы всего ≤ 75 000 €
  в год, доходы от необлагаемых… точнее _облагаемых_ (no exentas) рент ≤ 2 000 € и все они под
  удержанием (art. 124.3 LIS, подтверждено AEAT). Клубу с заметными aportaciones это условие не
  выполнить — значит, Modelo 200 и учёт доходов/расходов с разделением exentas / no exentas.
- IVA: членские взносы за поддержание ассоциации — вне IVA; aportaciones за потребление и побочная
  торговля (мерч, напитки) — по критерию администрации облагаются (прорrata по вычету). Экономическое
  исследование ассоциаций Наварры 2019–2020: ~85 % доходов клубов — cuotas de consumo, и именно их
  администрация считает облагаемыми 21 % IVA и 25 % IS. Отсюда вывод для модели: **у каждой проводки
  дохода — признак «exenta / sujeta», у клуба — две категории взносов** (mantenimiento и consumo).
- Наличные: THC Abogados предупреждает о рисках оплат наличными в клубах — нужны индивидуальные
  квитанции на каждый приём денег, суммы по протоколу, актуальная книга кассы. В модели: способ оплаты
  обязателен, касса — отдельный счёт, квитанция участнику (recibo) — из TASK-801.

### Autónomo (студии: Ink Space, Plis Plas на старте)

- Estimación directa simplificada (оборот ≤ 600 000 €): книги по Orden HAC/773/2019 — **ventas e
  ingresos, compras y gastos, bienes de inversión** (+ provisiones y suplidos у профессионалов).
  Формат свободный (таблица, программа), AEAT публикует типовой формат.
- Поля книги **compras y gastos** (art. 3.1 Orden): номер полученной фактуры и серия (без фактуры —
  порядковый номер приёма), дата выдачи и дата операции, **имя и NIF выдавшего**, концепт с разбивкой
  по статьям расходов последней модели IRPF, база IVA / ставка / квота, сумма, признанная расходом
  для IRPF, ставка и сумма удержания IRPF. Разрешён сводный асьенто по счетам одного поставщика за
  день (до 6 000 € всего, до 500 € за операцию).
- Поля книги **ventas e ingresos** (art. 2.1): номер и серия фактуры, даты, имя и NIF получателя,
  концепт, база / ставка / квота IVA или сумма, удержание.
- Книга **bienes de inversión** (art. 4): номер фактуры, дата ввода в работу, описание, поставщик и
  NIF, стоимость приобретения и амортизируемая, метод и % амортизации, квота за период, накопленная,
  выбытие с датой и причиной.
- Формы: 303 (IVA, квартал), 390 (IVA, год), 130 (IRPF, квартал), 111/190 (удержания, если есть
  работники или профессионалы), 347 (контрагенты свыше 3 005,06 € за год с IVA; подача в феврале,
  срок для 2025 г. — до 2 марта 2026 по ряду источников, сверить в sede AEAT).

### SL (студии позже)

PGC PYMES, libro diario, cuentas anuales, Modelo 200, 303/390, 111/190, 347. Наша двусторонняя
проводка под капотом (счёт из категории и способа оплаты) закрывает libro diario без второго учёта.

### Verifactu и электронная фактура

RDL 15/2025: обязательность с 01.01.2027 (плательщики IS) и 01.07.2027 (остальные). 05.10.2026
Минфин анонсировал перенос всех ещё не вступивших обязанностей на октябрь 2028, в BOE на 17.10.2026
нормы нет — действуют даты 2027. Для нас: фактуры (TASK-801) с неизменяемыми строками и hash-цепочкой
уже сейчас, отправка в AEAT — TASK-803 после первых платящих студий.

### Зарплаты (nómina)

Структура: devengos (salariales / no salariales) → брутто; удержания: соцвзносы работника (≈6,5 %
по Orden PJC/297/2026, источники расходятся на десятые) и IRPF по modelo 145 работника; нетто. Взносы
работодателя ≈30–32 % сверх брутто. Удержанный IRPF — Modelo 111 квартально, 190 годовой. Для учёта
клуба и студии достаточно четырёх сумм на нóмину: брутто, IRPF удержанный, взносы работника,
взносы работодателя; нетто и полная стоимость считаются.

## 2. Что нужно владельцу (управленческий учёт)

Из разговоров с Вадимом и из того, что показывают Holded/Quipu владельцу малого бизнеса:

| Вопрос владельца                        | Что для этого нужно в модели                                |
| --------------------------------------- | ----------------------------------------------------------- |
| Сколько заработали и потратили за месяц | P&L по категориям и месяцам                                 |
| Сколько денег в кассе и на счёте        | счёт проводки (касса / банк), переводы между ними           |
| Что приносит деньги, что ест            | категории доходов и расходов, топ контрагентов              |
| Маржа по товарам и услугам              | **цена закупки** в поставке товара, себестоимость в заказе  |
| Выручка по мастерам (студии)            | сотрудник на проводке дохода / в заказе и записи            |
| Сколько стоит команда                   | нóмины как отдельный вид расхода с четырьмя суммами         |
| Укладываемся ли в план                  | бюджет по категориям и месяцам, план vs факт                |
| Хватит ли денег до конца квартала       | прогноз кассы: повторяющиеся расходы и ожидаемые доходы     |
| Что сдавать gestor и когда              | «цифры для форм» 303/130/111/347/200, экспорт книг по Orden |

## 3. Референсы: как устроен импорт расходов таблицей

- **Quipu** (autónomos, Испания). Шаблон книги compras y gastos — 22 колонки: ejercicio, periodo
  (1T–4T), концепт, fecha de expedición, fecha de operación, serie, número, número de recepción,
  fecha de recepción, NIF выдавшего (тип / страна / номер / имя), bien de inversión, sujeto pasivo,
  tipo de operación (1 nacional, 3 Europa, 6 intracomunitaria), tipo de IVA, base, cuota IVA (считается),
  total (считается), exenta, IVA deducible, IRPF, importe y fecha de pago. Категорий нет — «концепт по
  своей номенклатуре». Импорт — в меню Gastos (документирован только импорт нóмин).
- **Holded** (pymes). Импорт расходов по шаблону CSV/Excel: обязательные поля помечены `*`, поля,
  требующие предварительной настройки, — `^`; обязательны номер документа, дата, срок, имя контакта,
  NIF, единицы; остальное (адрес, товар, SKU, цена, скидка, теги, счёт оплаты, счёт расхода, валюта) —
  по желанию. Пустые строки ломают импорт; документ из нескольких строк — повтор номера на каждой.
- **Yo-Facturó**: режим «только проверить» перед сохранением — полезная деталь.

Вывод для нас: **один шаблон на доходы и расходы**, колонки по Orden HAC/773/2019, минимум
обязательных, остальное пусто; скачать шаблон с примером строк, загрузить, увидеть отчёт по строкам
(ошибки, дубли, что создастся), подтвердить. Дубли — по (NIF, номер документа, дата).

## 4. Решения для v1 — «не усложнять»

1. **Издержки сразу** (TASK-798): таблица проводок доходов и расходов с категорией, контрагентом,
   документом, налогом, способом оплаты и счётом; категории из пресета (клуб / студия); импорт и
   экспорт таблицей; шифрование сумм и контрагентов envelope-ключом портала (решение Вадима, цена —
   один сервис).
2. **Себестоимость** (TASK-804): поставка товара с ценой за единицу = приход на склад + проводка
   расхода; маржа по товарам в отчётах. Без этого управленческий учёт не отвечает на главный вопрос.
3. **Нóмины** (TASK-805): отдельный вид расхода с четырьмя суммами и сотрудником, цифры для 111/190.
4. **Позже** (TASK-806): повторяющиеся расходы по расписанию, основные средства и амортизация.
5. **Фактуры и Verifactu, E2E-сейф, подача в AEAT** — как в плане (801, 802, 803).

Не делаем в v1: банковские выписки и сверку, многовалютность, прорrata IVA автоматом (признак
exenta/sujeta есть, расчёт — gestor), интеграцию с nómina-сервисами.

## 5. Шаблон импорта (черновик)

| Колонка       | Обяз. | Пример                       | Примечание                                      |
| ------------- | ----- | ---------------------------- | ----------------------------------------------- |
| `tipo`        | да    | `gasto` / `ingreso`          |                                                 |
| `fecha`       | да    | `2026-10-05`                 | дата операции; `fecha_factura` отдельно, если ≠ |
| `categoria`   | да    | `alquiler`                   | код категории портала; список в шаблоне         |
| `concepto`    | да    | `Alquiler local octubre`     |                                                 |
| `contraparte` | нет   | `Inmobiliaria Sol SL`        | создаётся, если нет                             |
| `nif`         | нет   | `B12345678`                  | обязателен для фактур, 347 и книг autónomo      |
| `documento`   | нет   | `F-2026-118`                 | серия и номер фактуры / чека                    |
| `base`        | да    | `1000.00`                    | без IVA                                         |
| `iva_pct`     | нет   | `21`                         | пусто = 0; `exenta` для необлагаемых            |
| `iva`         | нет   | `210.00`                     | считается, если пусто                           |
| `irpf_pct`    | нет   | `15`                         | удержание у профессионала                       |
| `total`       | нет   | `1210.00`                    | сверяется с базой и налогами                    |
| `pago`        | да    | `banco` / `caja` / `tarjeta` | счёт и способ                                   |
| `fecha_pago`  | нет   | `2026-10-06`                 |                                                 |
| `notas`       | нет   |                              |                                                 |

Экспорт — те же колонки плюс служебные (`id`, `creado_por`, `periodo`), и отдельный экспорт «книга
compras y gastos / ventas e ingresos» в порядке полей Orden HAC/773/2019.
